# 批量手机电脑传照片 📷

一个轻量级的**局域网图片上传工具**：

- 在你电脑上启动后，手机扫码 / 输入局域网地址即可**拍照即传**或**批量选图上传**
- 图片自动按顺序编号保存到桌面「上传图片」文件夹（`1.jpg`、`2.jpg`、`3.jpg` … 上限 100 张）
- 系统托盘常驻，可一键启动/停止服务、打开浏览器、切换保存目录、重置编号
- 单文件 exe，无需安装，开箱即用

## 功能

| 功能 | 说明 |
|---|---|
| 拍照即传 | 手机点大按钮 → 调起相机 → 预览 → 确认自动上传，可连续拍 |
| 批量选文件 | 一次选多张，自动分批上传 |
| 顺序编号 | 按上传顺序保存为 `1.jpg`、`2.jpg`…，最多 100 张 |
| 托盘管理 | 右键图标：启动/停止、打开浏览器、选目录、重置编号、退出 |
| 二维码 | 页面自动显示访问地址的二维码，手机扫一下就能传 |

## 使用

### 方法一：直接运行 exe（推荐）

1. 把 `dist/批量手机电脑传照片.exe` 拷到任意位置
2. 双击运行 → 系统托盘出现蓝色相机图标
3. 右键托盘图标 → 「打开浏览器」，或者直接在手机/电脑访问
   `http://<本机局域网IP>:8080`
4. 手机扫码或输入地址 → 选拍照 / 选文件 → 上传

> 首次运行会在桌面创建「上传图片」文件夹存放图片。配置保存在
> `~/.photo_transfer.json`，可以改保存目录和端口。

### 方法二：源码运行

```powershell
pip install pystray pillow qrcode
python main.py
```

## 打包

```bash
pip install pyinstaller
python make_logo.py   # 重新生成 logo（可选）
python build.py       # 生成 dist/批量手机电脑传照片.exe
```

## 技术栈

- Python 3.8+
- 标准库 `http.server` / `socket` / `threading`
- `pystray` 系统托盘（可选，无此依赖时退化为前台服务）
- `Pillow` 图标生成
- `qrcode`（页面通过 `api.qrserver.com` 在线生成二维码，离线时自动隐藏）

## 注意事项

- 手机和电脑必须在**同一局域网 / Wi-Fi** 下
- 如果 8080 端口被占用，可以改 `main.py` 顶部的 `PORT` 或在配置文件中改 `port`
- 编号不会自动循环，想重新从 1 开始 → 清空保存目录或点托盘「重置编号」
- 上传上限 100 张（`MAX_FILES`，可在 `main.py` 中改）
